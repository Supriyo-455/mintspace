# MintSpace - Project Status & Roadmap

## [Completed & Shipped]:
- [x] Moved away from MySQL to embedded, zero-dependency SQLite (modernc.org/sqlite).
- [x] Content-Addressable Storage (CAS):
    - Implemented BlobStorage interface with LocalCASStorage.
    - All blogs stored canonically as raw Markdown indexed by SHA-256 hash.
    - Raw markdown inspectable via /blob/<hash>.
    - Ready for drop-in distributed storage (IPFS/Arweave/MinIO).
- [x] Research Paper UI Design System:
    - Academic serif typography (Newsreader, EB Garamond, Computer Modern styling).
    - Scholarly masthead ("MINTSPACE // OPEN RESEARCH ARCHIVE").
    - Academic paper presentation: Title, author affiliation, date, SHA-256 integrity badge.
    - Indented Abstract block.
    - KaTeX math formula rendering ($E=mc^2$ and block math $$...$$).
    - Clean academic tables, footnotes, and blockquotes.
    - BibTeX citation generator with one-click copy.
- [x] Scholarly Endorsements (Likes):
    - Interactive AJAX toggle with live counter updates.
- [x] Peer Review & Discussion (Comments):
    - Formal commentary section for scholarly feedback.
- [x] Access Control & Private Blogs:
    - Public vs. Restricted/Private manuscript policy.
    - Protected via middleware and database filtering.
- [x] Editorial Board & Administration Console (/admin):
    - Dashboard statistics (manuscripts, scholars, comments, likes).
    - Manage manuscripts (audit, delete/retract).
    - Manage users (promote to editor/admin, revoke admin).
- [x] Security Fixes:
    - Patched JWT middleware bypass vulnerability.
    - Secure identity extraction from verified JWT cryptographic claims.
    - Bluemonday UGC policy sanitization preventing XSS while allowing math and code tags.
- [x] Default Editorial Seed Data:
    - Default admin: admin@mintspace.io / admin123.
    - Seeded initial scholarly paper on Content-Addressable Storage.
